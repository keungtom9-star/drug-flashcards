# iPhone UI and search-flow checks

Run `npm test` with Node.js 18+ for the dependency-free regression suite. It exercises the application scripts with small browser mocks and the service worker with a simulated cache. It does not replace rendering tests.

Serve the repository as a static site, for example `python3 -m http.server 8000`, then visit `/index.html`. Also test under a subdirectory such as `/drug-flashcards/`, matching GitHub Pages.

## Device checks before merging

- On a small iPhone and a larger iPhone, check portrait and landscape in Safari and after Add to Home Screen. All four navigation tabs should remain reachable with no horizontal page overflow or overlap with the home indicator.
- Tap the small app icon or `AI Drug Tutor` title from Search, Revise, Ward and Clinical. It should return to the clean main Search page without opening the keyboard. With the keyboard closed, confirm the compact four-tab bar stays directly below the header, the content reaches the lower safe area, and there is no duplicate or floating navigation.
- In Search, focus the empty input with the keyboard visible. The API reminder, history, system browser and bottom tabs should move out of the way. Type a generic name, brand, drug class or condition and confirm results stay visible; the top Back button should clear the search and restore the normal screen. Also check multi-word and mixed-case queries, browse by system, expand a drug result, and load more than 30 matches.
- Submit several searches, return to the empty search screen, and confirm recent searches are de-duplicated, tappable and persist after a reload.
- Open Revise, confirm Random 10 shows one vertical column of 10 floating cards, then enter a disease such as `heart failure`. Confirm the app removes duplicate generic/brand/salt entries, makes one repair request when the first answer is short, and keeps any valid partial list rather than hiding everything. Confirm the status reports how many medicines were found in the loaded database, matched cards say `In database · saved details`, unmatched cards say `Not in database · AI draft`, and nothing is added to the device or Google Sheet. Confirm unmatched Nursing care says it was not generated by this AI search.
- On an official missing-drug result, generate Nursing care with DeepSeek. Confirm the final editable field contains exactly three short sentences in one paragraph, with no bullets; if the model returns a different format, the previous field value is restored.
- Expand and collapse results, switch all four tabs, and open/close each modal. Confirm the spring transitions are smooth, controls stay readable, and Reduce Motion disables decorative movement.
- Open Google and Drugs.com from a drug result. Each should load the intended external result instead of showing an empty in-app browser sheet, and returning to the app should preserve the search.
- With the active provider's API key empty, confirm local search still works and the Add API key action opens Settings at the correct field. Save and clear a key, confirming the reminder updates immediately.
- Select `Qwen3.8 27B (Free · Secure)` and confirm no API-key field appears in the browser. AI data improvement and Cantonese explanation should call only `/.netlify/functions/openrouter-qwen`; browser requests must not contain an `Authorization` header. With `OPENROUTER_API_KEY` removed from Netlify, the function should return a clear configuration error without exposing any secret.
- Search for a drug missing locally but present in the latest Google Sheet; it should appear in an editable review form without calling AI or adding anything. Edit a field, tap Add to this device, and confirm the edited version becomes searchable.
- Search for a drug absent from both local data and Google Sheet. AI should return an editable review form without automatically adding or writing anything. Edit the name, indication and side effects, then choose Add to this device or Add to Google Sheet + device; confirm only that explicit action saves the edited values.
- During AI drug search and 廣東話解釋, confirm text appears progressively instead of waiting for the full response. Try a slow connection and verify split streaming chunks do not lose words; the final drug result must still become an editable review form.
- Confirm Side Effects contains useful adverse effects and never shows `Not specified`, `Not listed`, `Unknown` or `N/A`; blank / placeholder side effects must block Add. Tap 廣東話解釋 and confirm the final answer uses short, readable Traditional Chinese Cantonese sections; English is limited to necessary drug names and medical terms.
- Open Settings, focus the last input, and scroll to Save while the keyboard is visible. Check that text inputs do not trigger unwanted zoom and that manual pinch zoom is still possible.
- In Clinical Bank, open a topic, answer, move forward and back. The original selection and rationale should remain visible, with no extra score. A fresh session starts at 0%; generated previews do not alter a library-session score. Check topic search, Settings, and the generator entrance.
- In Ward, open Labs and search `sodium`, `INR`, `troponin`, `HbA1c`, `lactate` and `anion gap`. Check every category chip, clear button, card expansion and the official-guidance carousel. Confirm there is no duplicated safe-area gap above the Labs tab, every card shows its range and chevron, the local-range warning remains visible, and the page has no horizontal scrollbar.
- In Ward Labs, read the ABG / VBG five-step guide on the narrowest iPhone. Confirm the table clearly says that PvO₂ must not be used for oxygenation, identifies when ABG is preferred, and keeps the Winter's formula line readable without clipped subscripts or units.
- In Ward, open Imaging and search `KUB`, `CT brain`, `droppler`, `MRI spine`, `VFSS`, `TEE`, `EF` and `contrast`. Check the X-ray, USG, CT, MRI, Echo, Fluoro, Nuclear and Safety chips, clear button, single-result auto-expand, card transitions and the horizontally scrolling official reference links. Confirm every card title and chevron stays visible, only the filter/reference rows scroll sideways, and the page itself has no horizontal scrollbar on the narrowest supported iPhone.
- In Ward, open the separate Infusion tab. Use both jump buttons and confirm every NTEC MSSC 2024 infusion-pump and syringe-pump regimen appears as a full-width stacked card on iPhone, with preparation, dose/rate and remarks readable without zooming or horizontal page scrolling. Confirm the same tables remain three columns on iPad/desktop and that the Meds tab starts directly with the searchable injectables list.
- Cold-load the Home page on a throttled iPhone connection. Confirm Search becomes usable before optional Google Sheet sync and Ward/Clinical prewarming begin, then reopen once to confirm the split `drugs.js` data is served from the PWA cache. Tap `廣東話解釋` and confirm the first Cantonese fragment appears while Qwen is still generating, headings/lists remain readable, and an English-only first attempt is never shown before the Cantonese retry.
- Load all three pages online and allow the service worker to activate. Load a clinical question sheet successfully once, then go offline and reopen Home, Ward, and Clinical. Each URL should show its own page; the saved clinical question bank should remain usable. Uncached AI generation, remote images and new CSV downloads require connectivity.

## Validation limitations in this change

The automated regression suite and Vite production build passed. The available remote browser could not reach the local preview, so Safari rendering, virtual keyboard behavior and installation on a physical iPhone remain unchecked.

## Credential follow-up

The embedded provider key was removed from the current source. The repository owner should revoke/rotate that previously exposed key with its provider; deleting the default does not revoke it or remove it from Git history. Enter a replacement only in the app's Settings, never in source code or a PR comment. Existing keys saved on a device are not changed by this patch.
